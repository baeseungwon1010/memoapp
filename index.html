사각노트 개인정보처리방침

시행일: 2026년 10월 25일 · 앱: 사각노트 (com.protoparse.note)

사각노트(이하 "앱")는 손글씨 메모 앱입니다. 앱은 회원가입이나 로그인이 없고, 광고가 없으며, 인터넷 권한이 없어 사용자의 메모나 개인정보를 기기 밖으로 보내지 않습니다. 아래는 앱이 다루는 정보와 처리 방식입니다.

1. 기기 안에만 저장되는 정보

다음 정보는 사용자의 기기 안 앱 전용 저장 공간에만 저장되며, 개발자에게 전송되지 않습니다.

  • 메모 내용: 손글씨, 텍스트, 체크리스트, 태그, 폴더, 넣은 사진, 가져온 문서의 페이지 이미지
  • 음성 메모: 사용자가 녹음 버튼을 눌렀을 때만 마이크로 녹음하며, 녹음 파일은 해당 메모 안에만 저장됩니다.
  • 앱 설정: 펜 종류·색·굵기, 화면 설정 등

앱을 삭제하면 이 정보도 함께 삭제됩니다. 휴지통으로 옮긴 메모는 30일 후 자동으로 영구 삭제됩니다.

2. 권한

권한사용 목적
마이크 (RECORD_AUDIO)음성 메모 녹음. 사용자가 녹음을 시작할 때만 사용하며, 앱 화면을 벗어나면 녹음을 멈춥니다.
생체 인식·화면 잠금비밀 메모를 열 때 기기의 화면 잠금(지문·얼굴·PIN 등)으로 본인 확인. 확인은 안드로이드 시스템이 처리하며, 앱은 지문·얼굴 정보를 받거나 저장하지 않습니다.

사진·문서는 안드로이드 시스템의 파일 선택 화면으로 사용자가 직접 고른 파일만 읽습니다.

3. 백업

  • 앱 안의 "백업 만들기": 사용자가 고른 위치에 메모 전체를 zip 파일로 저장합니다. 이 파일은 암호화되지 않으므로 보관 위치에 주의해 주세요.
  • 안드로이드 자동 백업: 기기 설정에서 Google 백업이 켜져 있으면, 안드로이드가 앱 데이터를 사용자의 Google 계정에 백업할 수 있습니다(Google 정책 적용).

4. 외부로 전송되는 정보

없습니다. 앱에는 인터넷 권한이 없고, 분석·광고·오류 수집 도구를 넣지 않았습니다. 사진·문서(PDF·PPT·PPTX·HWP·HWPX) 가져오기도 기기 안에서 처리합니다. 앱이 비정상 종료되면 원인을 기기 안에만 기록해 다음 실행 때 보여 주며, 사용자가 직접 복사해 전달하지 않는 한 개발자에게 전송되지 않습니다.

5. 제3자 제공·광고·추적

앱은 사용자의 정보를 판매하거나 제3자에게 제공하지 않으며, 광고 식별자나 위치 정보를 사용하지 않습니다.

6. 아동

앱은 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
