사각노트 개인정보처리방침

시행일: 2026년 10월 16일 · 앱: 사각노트 (com.protoparse.note)

사각노트(이하 "앱")는 손글씨 메모 앱입니다. 앱은 회원가입이나 로그인이 없고, 광고가 없으며, 개발자가 운영하는 서버로 사용자의 메모나 개인정보를 보내지 않습니다. 아래는 앱이 다루는 정보와 처리 방식입니다.

1. 기기 안에만 저장되는 정보

다음 정보는 사용자의 기기 안 앱 전용 저장 공간에만 저장되며, 개발자에게 전송되지 않습니다.

  • 메모 내용: 손글씨, 텍스트, 체크리스트, 태그, 폴더, 넣은 사진, 가져온 문서의 페이지 이미지
  • 음성 메모: 사용자가 녹음 버튼을 눌렀을 때만 마이크로 녹음하며, 녹음 파일은 해당 메모 안에만 저장됩니다.
  • 앱 설정: 펜 종류·색·굵기, 화면 설정 등

앱을 삭제하면 이 정보도 함께 삭제됩니다. 휴지통으로 옮긴 메모는 30일 후 자동으로 영구 삭제됩니다.

2. 권한

권한사용 목적
마이크 (RECORD_AUDIO)음성 메모 녹음. 사용자가 녹음을 시작할 때만 사용하며, 앱 화면을 벗어나면 녹음을 멈춥니다.
인터넷아래 4번의 문서 변환과 5번의 손글씨 인식 모델 내려받기(둘 다 선택 기능)에 사용합니다.
생체 인식·화면 잠금비밀 메모를 열 때 기기의 화면 잠금(지문·얼굴·PIN 등)으로 본인 확인. 확인은 안드로이드 시스템이 처리하며, 앱은 지문·얼굴 정보를 받거나 저장하지 않습니다.

사진·문서는 안드로이드 시스템의 파일 선택 화면으로 사용자가 직접 고른 파일만 읽습니다.

3. 백업

  • 앱 안의 "백업 만들기": 사용자가 고른 위치에 메모 전체를 zip 파일로 저장합니다. 이 파일은 암호화되지 않으므로 보관 위치에 주의해 주세요.
  • 안드로이드 자동 백업: 기기 설정에서 Google 백업이 켜져 있으면, 안드로이드가 앱 데이터를 사용자의 Google 계정에 백업할 수 있습니다(Google 정책 적용). 아래 4번의 API 키는 백업에서 제외됩니다.

4. 외부 서비스로 전송되는 정보 (선택 기능)

DOCX(워드) 문서를 가져오는 기능은 사용자가 직접 발급한 CloudConvert API 키를 설정에 입력한 경우에만 동작합니다. 이 경우 사용자가 고른 DOCX 파일이 PDF 변환을 위해 HTTPS로 CloudConvert 서버에 업로드되고, 변환된 PDF를 내려받습니다. 전송된 파일은 CloudConvert의 개인정보처리방침에 따라 처리됩니다. API 키는 기기 안에만 저장되고 개발자에게 전송되지 않습니다. PDF·PPT·PPTX·HWP·HWPX 파일은 외부로 보내지 않고 기기 안에서 변환합니다.

5. 손글씨 검색 (선택 기능)

설정에서 "손글씨 검색"을 켜면 Google의 ML Kit 손글씨 인식 모델을 한 번 내려받고, 펜으로 쓴 필기를 기기 안에서 글자로 인식해 검색에 사용합니다. 필기 내용과 인식된 글자는 기기 밖으로 보내지 않습니다.

다만 ML Kit은 기능 개선과 오류 진단을 위해 다음 정보를 HTTPS로 Google에 보냅니다: 기기 정보(제조사, 모델, OS 버전), 앱 패키지 이름과 버전, 사용자나 기기를 식별하기 위한 것이 아닌 설치별 식별자, 성능 수치(처리 시간 등), 기능 설정(인식 언어), 입력·출력 크기, 기능 사용·모델 내려받기 등의 이벤트와 오류 코드. 자세한 내용은 ML Kit 데이터 공개와 Google 개인정보처리방침을 참고하세요. 손글씨 검색을 끄면 인식해 둔 글자와 모델을 지웁니다.

6. 제3자 제공·광고·추적

앱은 사용자의 정보를 판매하거나 제3자에게 제공하지 않으며, 광고 식별자나 위치 정보를 사용하지 않습니다.

7. 아동

앱은 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
